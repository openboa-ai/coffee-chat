# Fixed Init contract

The only Bean content license is `CC-BY-4.0` with the official link at
<https://creativecommons.org/licenses/by/4.0/>. The Preview must state public
Beans; sharing, commercial use, and AI adaptations; attribution, license link,
change indication, and no endorsement; irrevocability; rights authority; Origin
exclusion; and that AI Coffee is not publisher-authored or endorsed.

The Preview digest must also bind metadata obtained through the trusted
repository boundary: canonical public repository identity, exact official
parent, visibility, default branch, and observed full commit. A caller-supplied
object is not verified metadata.
