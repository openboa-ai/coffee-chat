# Coffee Chat support

Publisher: Openboa AI

Source and issue tracker: <https://github.com/openboa-ai/coffee-chat>

Security reports: use the repository's private GitHub security-advisory
interface as described in `SECURITY.md`.

Support covers the repository-owned Skills, deterministic runtime, manifests,
package, and documented fixed contract. Include the release identifier,
repository commit, package receipt digest, selected Skill, structured error
code, and redacted reproduction steps. Do not submit private Beans, credentials,
tokens, or personal data.

Local marketplace discovery is authoring evidence only. Codex Desktop and
ChatGPT Work are unsupported until `submission/surface-support.json` records
package-matched integration evidence. Unsync cannot remove remote repositories
or host history; use the host's own controls for conversation retention and
deletion.
